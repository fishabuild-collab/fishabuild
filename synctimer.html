The problem

Running a multi-room hackathon, the timing was held together by hand: separate countdowns per room, nothing in sync, and a stage screen that kept losing the timer behind other windows. Setup alone ate about 90 minutes every event, and a single mistimed round threw the whole schedule.

What I built

  • A shared timer with real-time synced state, so every room and the main stage read the same clock
  • Picture-in-picture, always-on-top mode: the countdown stays visible over slides, demos, anything
  • Room URLs + QR join, so participants are on the right timer in one scan
  • Admin-only control, so only the host can start, pause, or reset
  • Shipped v1, then v2 with the always-on-top fix, deployed on Vercel

The result

Setup dropped from roughly 90 minutes to 20. The hardest moment was live: the key fix went in on-site, about an hour before doors, and held through the event. Built solo, start to finish.
